# AI usage disclosure

Generative AI assistance was used during development for:

- project planning and phase breakdown
- explaining Python, Git, Pygame, and search-algorithm concepts
- debugging syntax, imports, UI layout, and test failures
- suggesting refactoring approaches
- drafting unit tests
- drafting README, source attribution, report structure, and release instructions
- reviewing benchmark and heuristic explanations

The development team remained responsible for:

- deciding which changes to accept
- integrating code into the repository
- checking source-code compatibility
- running the complete test suite
- validating game behavior manually
- reviewing algorithm correctness
- collecting final benchmark data
- writing the final conclusions
- preserving third-party licenses and attribution

AI-generated suggestions were not treated as automatically correct. Changes were accepted only after local testing and review.
